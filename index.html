좌우 여백은 문자 위치를 조절합니다. 프린터 절단 전후에 생기는 물리적 테이프 여백은 별도입니다.

절단 · 테이프 절약 설정

이 값은 절단 후 여백을 줄이는 기능이 아니라 인쇄 내용 사이에 빈 테이프를 추가하는 설정입니다. 0mm가 낭비 최소입니다.

기구상 첫 라벨의 선행 테이프를 완전히 없앨 수는 없습니다. 연속 인쇄는 마지막 테이프 절단/배출을 보류하므로 일반적인 한 장 인쇄에는 사용하지 마세요.

미리보기

열전사 인쇄용 흑백 이미지 미리보기입니다. 문자 배치 여백은 위 조절값을 반영합니다. 실제 절단 전후 여백은 프린터에서 별도 검증해야 합니다.

USB 연결 · Ubuntu 설정

Brother PT-P700 프린터를 Ubuntu PC의 USB 포트에 연결하고 전원을 켜세요. 프린터의 Editor Lite(PLite) 표시등은 끄세요.

  1. GitHub 프로젝트를 Ubuntu PC에 다운로드합니다.
  2. 설치 스크립트를 이용해 인쇄 프로그램과 USB 접근 규칙을 설정합니다.
  3. 최초 설치 후 자동 실행 서비스를 활성화하면 다음부터 터미널 실행 없이 웹에서 사용할 수 있습니다.
git clone https://github.com/Yuul-Jung/pt-p700-web.git
cd pt-p700-web
bash install-ubuntu.sh
bash enable-autostart.sh

Ubuntu 시스템에 대한 최초 설치 및 프로그램 업데이트는 사용자 승인과 OS 권한이 필요합니다. 웹에서 직접 설치하지는 못합니다. 설치 및 자동 시작 등록은 최초 한 번만 필요합니다. 이후 Ubuntu 로그인 시 로컬 서버가 실행됩니다. 이 페이지는 프린터 USB를 직접 열지 않고 Ubuntu 로컬 서버를 통해 출력합니다.

연결 상태: 확인 준비 중

USB 인식 상태와 실제 인쇄 가능 여부는 다를 수 있습니다. 테스트 인쇄는 테이프를 소비합니다. 브라우저 설정에 따라 로컬 서버 접근이 차단될 수 있습니다.
