라벨 내용 및 문자 여백 미리보기 · 프린터 기구적 절단 여백은 별도

라벨 · 글자 설정

선택한 글꼴이 미리보기에 적용됩니다.
각 행의 글자 크기를 개별 조절합니다.

절단 · 테이프 절약

추가 빈 테이프 0mm 권장 · 기계적인 선행 여백은 별도입니다. 연속 인쇄는 최종 절단이 보류될 수 있습니다.

USB 연결 상태

연결 상태: 확인 준비 중

이미지 · 로고

이미지를 복사한 뒤 Ctrl+V · 또는 이 영역을 클릭하고 붙여넣기
스크린샷, 복사한 PNG/JPG 이미지 지원
파일 선택 또는 클립보드 이미지 붙여넣기
선택 시 이미지를 1행 왼쪽에 통째로 배치하며, 1행 글자가 이미지 오른쪽부터 시작합니다. 기존 자유 배치는 체크 해제.
업로드된 이미지의 글자를 인식하여 편집 가능한 텍스트로 변환합니다.

원본 가로세로 비율을 유지합니다. 이미지의 X/Y는 라벨 왼쪽 위 기준이며 글자와 겹치면 마지막에 그려진 글자가 위에 표시됩니다. 이미지와 글자가 겹치지 않도록 위치를 조절하세요.

Ubuntu Linux 전용 · 최초 USB 설치 안내 (필요한 경우에만 펼치기)

최초 설치 시 PT-P700 USB 연결 및 PLite 표시등 OFF를 확인하세요.

git clone https://github.com/Yuul-Jung/pt-p700-web.git
cd pt-p700-web
bash install-ubuntu.sh
bash enable-autostart.sh

설치 및 로그인 자동 실행 등록 후에는 일반 인쇄에 터미널이 필요하지 않습니다. USB 드라이버의 설치와 서버 프로그램 변경은 웹페이지만으로 수행할 수 없습니다.
